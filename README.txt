# 🔥 SMOKEWATCH – Smoke Detection Monitoring System

A web-based Smoke Detection Monitoring System developed using **HTML, CSS, and JavaScript**. SMOKEWATCH provides a dashboard to monitor simulated smoke sensor readings, identify potential smoke-related risks, and display alerts when predefined threshold values are exceeded.

The application is designed as an academic project demonstration and can be accessed through a web browser.

---

## 📌 1. Project Overview

SMOKEWATCH is a front-end web application that demonstrates how a smoke detection monitoring system can work.

It displays simulated sensor readings through an interactive dashboard. The system continuously updates the readings, evaluates them against predefined threshold values, and displays the corresponding monitoring status.

The primary objective is to demonstrate the concept of real-time smoke monitoring and alert generation through a simple and user-friendly interface.

## ✨ 2. Features

- **Interactive Dashboard:** Displays smoke monitoring information in an organized interface.
- **Simulated Sensor Readings:** Generates smoke sensor values for demonstration purposes.
- **Threshold-Based Monitoring:** Compares sensor readings against predefined threshold values.
- **Status Indication:** Displays monitoring conditions based on the detected readings.
- **Alert Generation:** Displays visual alerts when readings exceed critical threshold levels.
- **Responsive Design:** Provides a user-friendly interface across different screen sizes.
- **Dynamic Updates:** Updates dashboard information using JavaScript.

## ⚙️ 5. How to Run the Project Locally

Follow these steps to run SMOKEWATCH on your computer.

1. Download or clone this repository.
2. Extract the ZIP file if you downloaded the project as a ZIP.
3. Open the extracted project folder in Visual Studio Code.
4. Make sure all three files (`index.html`, `style.css`, and `script.js`) are present in the same folder.
5. Open `index.html` using the Live Server extension.

Alternatively, you can open `index.html` directly in your web browser.

## 🌐 6. Deployment Using Netlify

SMOKEWATCH can be deployed using Netlify to make the application accessible through a public URL.

**Deployment Steps:**

1. Upload the project files to a GitHub repository.
2. Visit [Netlify](https://www.netlify.com/).
3. Log in to your Netlify account.
4. Select **Add new project** and choose the option to import an existing project.
5. Connect your GitHub account if required.
6. Select the SMOKEWATCH repository.
7. Configure the deployment settings if necessary.
8. Click **Deploy**.

Alternatively, use Netlify's manual deployment option and drag and drop the project folder containing `index.html`, `style.css`, and `script.js`.

Once deployment is complete, Netlify will generate a public URL through which the application can be accessed.

## 🔍 7. Working Principle

The application follows a simple monitoring workflow:

1. The user opens the SMOKEWATCH dashboard.
2. The application initializes the monitoring interface.
3. JavaScript generates simulated smoke sensor readings.
4. The readings are validated and processed.
5. The threshold analysis module evaluates the readings.
6. The monitoring status is determined.
7. A visual alert is displayed if the reading exceeds the critical threshold.
8. The dashboard updates to reflect the latest monitoring information.

## ⚠️ 8. Project Limitations

- The application uses simulated sensor readings rather than actual hardware sensor data.
- It is not currently integrated with physical smoke detectors.
- It does not provide actual fire detection or emergency response services.
- It does not send SMS, email, or mobile push notifications.
- It is not a certified fire safety or alarm system.

**Safety Notice:** SMOKEWATCH is an academic demonstration project intended for educational purposes only. It must not be used as a substitute for certified smoke detectors, fire alarms, or professional fire safety equipment.
